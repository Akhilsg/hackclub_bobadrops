# My project

HTML: 
- includes two headings, a subheading, a paragraph text, and an image. 
 - inside the paragraph text are bold, underline, and italics tags to show that styling can be done with html tags as well, not just css,
 - span and div tags as containers

CSS: 
- the first heading has a linear gradient background with curved edges and a cool elevation effect that becomes more apparent when you hover over the heading.  
- we use a flexbox to contain the span with the css class in the same line as the other text and align them vertically using align-items: center;
- the image moves side to side using an infinite and alternating keyframes animation that translates the image from the left to the right with an ease-in-out function
